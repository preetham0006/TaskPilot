# TaskPilot

A Java console-based Task Management System built using Object-Oriented Programming principles.

## Features

- Add Task
- Display All Tasks
- Find Task by ID
- Update Task Status
- Delete Task
- Search by Priority
- Search by Status

## Technologies

- Java
- Java Collections Framework
- OOP

## Project Structure

src/
├── Main.java
├── ConsoleUI.java
├── Task.java
├── TaskManager.java
├── Priority.java
└── TaskStatus.java
